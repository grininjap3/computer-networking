# Task 2 – Collision and broadcast domains

Topology: 3 hubs with 8 PCs each connect to Switch-A; Switch-A connects to Router G0/0; Router G0/1 connects to Switch-B with 12 IP phones. Collision domains = 3 hub segments + 1 Switch-A/router + 1 router/Switch-B + 12 phone ports = 17. Broadcast domains = 2, separated by the router. Hub is OSI Layer 1; switch Layer 2; router Layer 3; end hosts use Layers 1–7. Replacing hubs with unmanaged switches raises collision domains to 41 but broadcast domains remain 2; VLAN, QoS, security and monitoring remain absent.
